# Style bible — Casual Works

Factory look. Flat, readable, Kenney-adjacent. Tokens live in shared/ui/theme.ts — this file is the prose version.

## Palette

Use shared/ui/theme.ts as canonical hex. Do not invent a second palette per mechanic unless the title README says so.

Default intent:
- High contrast HUD
- Simple geometric sprites
- No photoreal
- Portrait titles stay portrait; landscape stay landscape

## Do not

- Import Roblox or Exclusive palettes
- Generate UI chrome that replaces shared/ui
- Start a second mechanic while tap-portrait is the active title

## Art path

art/inbox → checklist → art/accepted → game assets folder.
Prefer shapes and Kenney CC0 over generated characters until a title overlay exists.
