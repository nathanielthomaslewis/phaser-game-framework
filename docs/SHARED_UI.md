# Shared UI contract

All titles, Phaser and later Godot, use the same chrome.

```
♪ mute          SCORE          II pause

              retry (gold)
```

- Type: Georgia / serif
- Background: `#0e1116`
- Accent / primary button: `#f4c542`
- Danger: `#e85d4c`
- Portrait canvas: 720×1280
- Landscape canvas: 1280×720
- Scale mode: FIT, letterbox on `#0e1116`

Godot graduates copy this layout, not a new HUD invention.
